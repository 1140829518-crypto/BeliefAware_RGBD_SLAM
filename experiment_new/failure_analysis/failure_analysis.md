# 失败案例分析与适用范围说明

本节用于说明基于时间一致性建模的动态目标判别方法在动态 RGB-D SLAM 中的适用范围和局限性。时间一致性模块通过跨帧概率累积抑制单帧语义检测抖动，能够提升动态目标判断的连续性，但该机制本质上引入了时间记忆。因此，在快速状态变化、短时目标出现和遮挡场景中，系统可能出现响应延迟或短时误判。

对应示意图见 `failure_case.png`。图中灰色区域表示真实动态区间，蓝色曲线表示单帧观测概率，绿色曲线表示时间一致性后的动态概率，虚线为动态判断阈值。

## 1. 时间一致性响应延迟

时间一致性模型通过历史概率累积降低动态概率的瞬时波动。当动态目标持续存在时，该机制可以有效避免单帧漏检造成的动态状态中断；但在动态目标刚进入或刚离开视野时，概率递推会产生一定响应延迟。

典型表现包括：

- 目标刚出现时，动态概率需要若干帧才能稳定超过阈值；
- 目标离开后，历史动态概率不会立即下降，可能在短时间内继续保持动态判断；
- 当场景中动态目标频繁进出视野时，前端特征筛选可能滞后于真实状态变化。

该问题说明，时间一致性模型适合处理连续动态目标和短时检测抖动，但不适合单独处理快速切换的动态状态。实际系统中应结合运动一致性、深度变化和对象跟踪结果，对状态切换进行约束。

## 2. 快速运动目标

快速运动目标在图像中停留时间短、位置变化大，单帧检测置信度可能呈现尖峰式变化。若时间窗口较大或概率衰减较慢，模型可能无法及时响应短时动态目标，导致动态区域未被充分剔除。

典型表现包括：

- 快速经过画面的行人只在少数帧中被检测到；
- 时间一致性后的概率曲线被平滑，峰值可能低于动态判断阈值；
- 动态特征点在短时间内仍可能参与跟踪，造成局部位姿估计扰动。

该问题与参数敏感性实验中的结论一致：较大的时间窗口能够提升平滑性，但会降低对快速变化的响应能力。因此，时间窗口不宜无限增大，应根据机器人运动速度和场景动态程度选择折中参数。

## 3. 遮挡情况下误判

遮挡场景下，动态目标可能暂时不可见，或被静态物体部分遮挡。时间一致性模型会保留上一阶段的动态概率，因此在遮挡发生后，系统可能继续将该区域或对象维持为动态状态。

典型表现包括：

- 人体被桌椅、墙体或其他物体遮挡后，动态概率下降较慢；
- 已经静止或离开视野的目标可能短时间内仍被判为动态；
- 若遮挡区域包含可用静态特征，过度剔除可能减少前端跟踪点数量。

该问题说明，时间一致性建模需要与对象级语义地图和几何一致性判断配合使用。仅依赖历史概率可能导致动态状态保持过久，而结合对象可见性、深度连续性和重投影误差可以缓解遮挡误判。

## 4. 适用范围

本文方法更适用于以下场景：

- 动态目标在视野中持续出现，例如行人缓慢移动或室内人员活动；
- 单帧语义检测存在短时漏检或置信度波动；
- 机器人需要在动态环境中保持较稳定的轨迹输出；
- 系统希望在语义动态处理和实时性之间取得平衡。

本文方法不适合作为唯一动态判别依据的场景包括：

- 目标高速穿越画面且只出现少数帧；
- 大面积遮挡导致动态目标长期不可见；
- 静态目标与动态目标频繁切换状态；
- 需要对动态状态变化进行极低延迟响应的高速机器人场景。

## 5. 论文表述建议

在论文中建议将该部分作为局限性分析或失败案例讨论。推荐表述为：

> 时间一致性建模能够有效抑制单帧语义检测的短时抖动，提高动态目标判断的连续性。然而，该机制引入了历史状态记忆，在快速运动目标、目标快速离开视野以及遮挡场景中可能产生响应延迟或短时误判。因此，本文方法更适用于中低速移动机器人在室内动态环境中的连续运行任务。对于高速动态目标或长时间遮挡场景，需要进一步结合对象跟踪、深度变化和几何一致性约束进行自适应更新。

该分析有助于明确本文方法的适用边界，避免将时间一致性模型描述为对所有动态场景均有效的通用判别机制。
