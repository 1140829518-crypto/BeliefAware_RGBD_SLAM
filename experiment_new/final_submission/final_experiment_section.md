# 4 实验

为验证本文所提出的基于时间一致性建模的鲁棒语义动态 RGB-D SLAM 方法的有效性，本章在公开 RGB-D 数据集上进行了实验评估。实验重点关注动态场景下的轨迹精度、局部运动稳定性、动态目标判别一致性以及系统运行效率。需要说明的是，本文方法的目标不是单纯追求每一项误差指标最低，而是在存在动态目标、遮挡和语义检测不稳定的情况下，提高动态目标处理的一致性，减少由误检和漏检导致的轨迹突变，从而提升动态环境下的整体鲁棒性。

实验结果主要包括 TUM RGB-D 动态序列实验、Bonn RGB-D Dynamic Dataset 补充实验、时间一致性模块验证、时间窗口参数敏感性分析以及模块消融实验。所有轨迹精度指标均基于估计轨迹与数据集真值轨迹进行对齐后计算，动态目标判别实验采用 Precision、Recall 和 F1-score 评价识别结果的稳定性。

## 4.1 数据集和评价指标

本文实验使用 TUM RGB-D 数据集和 Bonn RGB-D Dynamic Dataset。TUM RGB-D 数据集包含多种室内 RGB-D 序列，其中 `fr3_walking_xyz`、`fr3_walking_rpy` 等序列存在明显人体运动，适合评估动态目标对 SLAM 跟踪与建图的影响。Bonn RGB-D Dynamic Dataset 进一步提供了具有人员移动、同步运动和群体运动干扰的动态场景，可用于验证方法在不同动态模式下的泛化能力。

在 Bonn 数据集实验中，本文选取了三个动态序列：`rgbd_bonn_person_tracking`、`rgbd_bonn_synchronous` 和 `rgbd_bonn_crowd`，分别对应 walking、sitting 和 crowd 三类动态场景。所有方法使用相同的 RGB-D 输入、相机参数和轨迹评价程序。对比方法包括 ORB-SLAM3、DS-SLAM、Dyna-SLAM 和本文方法。

评价指标包括：

- ATE RMSE：绝对轨迹误差均方根，用于评价全局轨迹精度，单位为 m。
- RPE translation RMSE：相对位姿平移误差均方根，用于评价局部运动估计稳定性，单位为 m。
- FPS：系统平均处理帧率，用于评价实时性。
- Precision、Recall、F1-score：用于动态目标判别性能评价。
- Smoothness：轨迹平滑性指标，用于反映轨迹局部变化程度。
- Failure Rate：失败率或跟踪不完整程度，用于描述动态干扰下系统运行稳定性。

## 4.2 TUM RGB-D 实验

在 TUM RGB-D 动态序列上，本文重点分析动态目标对轨迹稳定性的影响。相比静态场景，动态人体会在前端特征提取和匹配阶段引入不稳定观测，若仅依赖单帧语义检测，动态区域判别容易受到漏检、遮挡和检测置信度波动影响，从而造成相邻帧中特征剔除策略不一致。本文通过时间一致性概率递推对动态目标状态进行跨帧累积，使动态区域判断由单帧决策转变为时序估计。

从动态比例鲁棒性实验可以看出，随着人为注入动态点比例由 0% 增加到 50%，各方法的 ATE 均呈上升趋势，说明动态点比例增加会显著降低 RGB-D SLAM 的定位精度。其中 ORB-SLAM2 对动态比例最为敏感，ATE 从 0.1157 m 上升到 0.6957 m，Failure Rate 从 0.0796 增加到 0.4996。本文方法在该实验中并未取得最低 ATE，Dyna-SLAM 和 DS-SLAM 在部分比例下具有更低的轨迹误差；但本文方法的 Failure Rate 随动态比例增加保持相对平缓，在 50% 动态比例下为 0.1108，明显低于 ORB-SLAM2 和 Dyna-SLAM。这说明本文方法更适合作为动态环境下兼顾鲁棒性和实时性的方案，而不是单纯以最低 ATE 为目标。

轨迹稳定性曲线进一步说明，动态目标处理策略不仅影响最终 ATE，也影响运行过程中的轨迹偏差波动。时间一致性建模能够抑制动态概率在相邻帧之间的突变，使被判定为动态的区域在短时遮挡或检测置信度下降时仍保持一定连续性，从而减少前端观测集合的剧烈变化。该结果支持本文方法在动态环境下具有更稳定运行趋势的结论。

## 4.3 Bonn 动态数据集实验

为进一步验证方法在真实动态 RGB-D 数据上的泛化能力，本文在 Bonn RGB-D Dynamic Dataset 上进行了对比实验。实验序列包括 walking、sitting 和 crowd 三类动态场景，分别对应人员移动、同步运动以及群体运动干扰。表中报告 ATE RMSE、RPE translation RMSE 和 FPS，轨迹对比图见 Fig. 4。

Bonn 实验结果表明，本文方法在 walking 和 sitting 序列上取得较低 ATE，分别为 0.0465 m 和 0.0418 m。在 crowd 序列上，Dyna-SLAM 的 ATE 为 0.0331 m，略低于本文方法的 0.0381 m；但本文方法在该序列上取得最低 RPE，为 0.0183 m，说明其局部运动估计具有较好的稳定性。同时，本文方法在三个 Bonn 序列上的 FPS 分别为 8.93、7.41 和 11.12，显著高于 DS-SLAM 和 Dyna-SLAM 在相同序列上的运行帧率。

从不同方法的表现可以看出，ORB-SLAM3 在运行速度上具有优势，但在强动态序列中 ATE 较大，例如 sitting 序列中 ATE 为 1.0614 m，crowd 序列中 ATE 为 0.9446 m。DS-SLAM 和 Dyna-SLAM 通过语义或几何动态剔除能够在部分序列中降低误差，但处理速度较低，尤其 DS-SLAM 在 sitting 序列上的 FPS 仅为 0.0282。本文方法在多数序列中保持接近或优于语义动态 SLAM 基线的轨迹精度，同时显著改善运行效率。

因此，Bonn 实验支持以下结论：本文方法不是单项精度指标的绝对领先方案，但在动态目标持续出现的场景中，能够在轨迹精度、局部运动稳定性和实时性之间取得较好的折中。对于移动机器人长期运行任务，这种稳定性和效率的平衡具有实际意义。

## 4.4 时间一致性模块验证

为验证时间一致性模块对动态目标判别的作用，本文比较了三种动态目标判断方式：YOLO 原始检测、YOLO 与运动一致性融合、以及加入时间一致性概率递推的本文方法。评价指标包括 Precision、Recall 和 F1-score，结果见 Fig. 2。

实验结果显示，YOLO 原始检测的 Precision 为 1.0000，Recall 为 0.8866，F1-score 为 0.9399。YOLO+motion consistency 方法的 Precision 仍为 1.0000，但 Recall 降至 0.4968，F1-score 降至 0.6638，说明仅依赖运动一致性会使动态判断过于保守，容易漏检动态目标。本文时间一致性方法的 Precision 为 0.9961，Recall 为 0.9139，F1-score 为 0.9532，在保持较高精度的同时提高了召回率和综合 F1-score。

动态概率变化曲线见 Fig. 1。可以观察到，YOLO 单帧检测结果在遮挡或检测置信度变化时会出现较明显波动，而时间一致性建模通过概率累积保留了动态状态的短时记忆，使动态概率曲线更加平滑。该机制能够降低单帧误检或漏检对 SLAM 前端特征筛选的影响，从而提高动态环境中的判断稳定性。

需要指出的是，时间一致性模型并不会消除所有误判。当目标快速进入或离开视野时，概率累积可能带来一定响应延迟；当长时间遮挡发生时，动态概率也可能暂时保持在较高水平。因此，时间一致性模块更适合用于抑制短时检测抖动和增强连续动态目标识别，而不是替代所有几何一致性约束。

## 4.5 参数敏感性分析

时间一致性建模中的时间窗口大小 N 会影响动态概率累积范围。为了分析该参数对系统性能的影响，本文设置 N=1、3、5、10、15，并记录 ATE、RPE、Smoothness 和 FPS，结果见 Fig. 3。

实验结果表明，随着时间窗口从 N=1 增加到 N=10，ATE 从 0.5519 m 降低到 0.5172 m，轨迹 Smoothness 从 0.0347 降低到 0.0291，说明适当增加时间窗口有助于抑制动态判别抖动，提高轨迹平滑性。当窗口进一步增加到 N=15 时，Smoothness 继续降低到 0.0286，但 ATE 回升到 0.5226 m，同时 FPS 从 N=1 时的 14.69 降至 13.54。这表明过大的时间窗口虽然能够增强平滑效果，但可能引入响应延迟，并带来一定计算开销。

RPE 在不同窗口下变化较小，范围为 0.06697 m 到 0.06701 m，说明窗口参数主要影响动态概率稳定性和轨迹平滑趋势，对局部相对位姿误差的影响较弱。综合 ATE、Smoothness 和 FPS，本文实验中 N=10 附近表现出较好的折中。实际应用中，时间窗口大小应根据机器人运动速度、动态目标速度和实时性需求进行设置。

## 4.6 消融实验

为分析不同模块对系统性能的影响，本文进行了模块消融实验。实验设置包括 Baseline、Baseline+Semantic Mask、Baseline+Temporal Consistency、Baseline+Object-level Semantic Map 和 Full Model。评价指标包括 ATE、RPE、FPS 和 Failure Rate，结果见 Fig. 5。

从现有结果可以看出，Full Model 的 ATE 为 0.4392 m，略优于 Semantic Mask 和 Object-level Semantic Map 两个变体的 0.4429 m，但未优于 Baseline 的 0.4314 m。Temporal Consistency 单独加入时 ATE 为 0.6561 m，RPE 为 0.1279 m，表现并不理想。这说明时间一致性模块并不是一个单独降低轨迹误差的后端优化模块，其作用主要体现在动态目标判别的稳定化。当时间一致性缺少合适的语义筛选和对象级地图约束配合时，可能由于响应延迟或动态状态保持而影响前端观测选择。

Full Model 的 FPS 为 14.98，高于 Semantic Mask 和 Object-level Semantic Map 变体，说明完整模型在当前实现中保持了较好的运行效率。然而 Full Model 的 Failure Rate 为 0.3517，并未优于 Baseline。该结果提示，单纯使用 ATE 或 Failure Rate 评价对象级语义建图模块可能不充分，因为对象级语义地图的主要作用还包括语义一致性、动态目标管理和地图可解释性，而这些收益并不一定直接反映为更低的轨迹误差。

因此，消融实验表明，本文方法的优势主要来自多模块协同：语义检测提供动态目标先验，时间一致性降低动态判别抖动，对象级语义地图提高动态对象管理能力。现有消融结果不支持“每个模块单独提升所有定位指标”的结论，但能够说明时间一致性模块在完整动态处理框架中具有稳定动态判断的作用。后续工作可进一步增加语义地图质量、动态点残留率和多次运行标准差等指标，以更全面评价各模块贡献。

综上，本文实验表明，时间一致性建模能够改善动态目标判别的连续性，并在 Bonn 动态数据集和 TUM 动态场景分析中体现出较稳定的运行趋势。虽然本文方法并不是每个序列中误差最低的方法，但其在动态场景下兼顾轨迹稳定性、实时性和语义动态处理能力，具有面向移动机器人动态环境应用的实际价值。
