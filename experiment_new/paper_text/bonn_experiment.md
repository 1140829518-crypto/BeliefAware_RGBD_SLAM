# Bonn RGB-D Dynamic Dataset 实验说明

为进一步验证本文方法在动态场景中的鲁棒性，除 TUM RGB-D 数据集外，本文增加 Bonn RGB-D Dynamic Dataset 作为补充实验。该数据集包含由 RGB-D 相机采集的动态室内序列，并提供相机轨迹真值，可用于评估动态目标干扰下不同 RGB-D SLAM 方法的定位精度与运行稳定性。

实验选取数据集中具有明显人员运动或群体运动干扰的动态序列。若本地数据集命名与论文描述不完全一致，实验脚本会自动从 `walking`、`sitting`、`crowd/person movement` 等关键词对应的可用动态序列中选择至少三组序列，并统一生成 RGB-D association 文件。所有方法使用相同 RGB 图像、深度图、相机内参和轨迹评价程序，以保证比较条件一致。

对比方法包括 ORB-SLAM3、DS-SLAM、Dyna-SLAM 以及本文方法。评价指标包括绝对轨迹误差 ATE RMSE、相对位姿误差 RPE translation RMSE 和系统运行帧率 FPS。ATE 与 RPE 用于衡量整体轨迹精度和局部运动估计误差，FPS 用于反映动态处理模块对实时性的影响。

需要强调的是，本文方法并非单纯追求最低 ATE。动态 RGB-D SLAM 在实际应用中不仅需要短时定位精度，还需要在动态目标持续干扰、遮挡和检测不稳定时维持轨迹连续性。单帧语义检测容易受到漏检、误检和遮挡影响，导致动态点剔除策略在相邻帧之间发生突变，从而引入轨迹抖动。本文通过时间一致性建模对动态概率进行递推更新，使动态目标判断由单帧决策转变为跨帧稳定估计，从而减少动态目标造成的轨迹突变，提高长期运行稳定性。

因此，在 Bonn 数据集实验中，除报告 ATE、RPE 和 FPS 外，本文还绘制包含 Ground Truth、ORB-SLAM3、DS-SLAM、Dyna-SLAM 和本文方法的轨迹对比图，并在 TUM 动态序列上补充轨迹偏差稳定性曲线。该曲线重点展示不同方法在运行过程中轨迹偏差的波动程度，用于说明时间一致性模块能够抑制动态干扰导致的瞬时不稳定，而不是仅依赖后端优化获得局部最优轨迹误差。

实验结果表明，当动态目标在视野中持续出现或发生遮挡时，本文方法通过时间概率累积保持更平滑的动态区域判别结果，在轨迹连续性和长期稳定性方面具有更好的表现。即使在某些序列上 ATE 不是所有方法中最低，本文方法仍能有效降低轨迹突变和动态目标误判带来的不稳定性，更符合服务机器人和移动机器人在真实动态环境中的连续运行需求。
