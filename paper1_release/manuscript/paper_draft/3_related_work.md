# 2 相关工作

## 2.1 RGB-D SLAM

RGB-D 相机能够同时提供彩色图像和深度信息，因此在室内移动机器人场景中被广泛应用。ORB-SLAM2、ORB-SLAM3 等特征点法 SLAM 系统通过 ORB 特征提取、匹配、局部建图和回环检测实现了较高精度的相机位姿估计。然而，这类方法通常依赖静态场景假设。当动态目标占据较大图像区域或持续参与特征匹配时，错误的动态特征会影响位姿估计和地图点维护。

## 2.2 动态环境 SLAM

为缓解动态目标对 SLAM 的影响，研究者提出了多种动态点剔除策略。一类方法基于多视图几何约束，通过光流、极线约束、重投影误差或运动一致性检测异常动态点。该类方法不依赖语义类别，但在相机快速运动、纹理不足或深度噪声较大时容易出现误判。另一类方法引入语义分割或目标检测模型，直接识别行人、车辆等潜在动态目标，并在前端剔除相关特征点。DS-SLAM、Dyna-SLAM 等方法在动态场景中取得了较好效果，但语义分割或实例分割模块通常计算开销较大，且单帧语义结果本身存在不稳定性。

## 2.3 语义 SLAM 与对象级地图

语义 SLAM 在几何地图之外引入类别、实例或对象级信息，使地图具有更强可解释性。对象级语义地图能够帮助机器人理解场景结构，并为动态对象管理、人机共融导航和长期地图维护提供支持。现有对象级语义 SLAM 方法通常关注静态对象建图或语义标签融合，对于动态目标状态的跨帧一致性处理仍然不足。动态对象若被错误加入静态地图，会造成地图污染；若过度剔除，又可能降低可用特征数量。因此，需要在语义表达和动态筛选之间取得平衡。

## 2.4 时间一致性建模

时间一致性思想广泛应用于目标跟踪、视频语义分割和动态场景理解。相比单帧判断，跨帧状态建模能够利用历史观测降低瞬时噪声影响。对于动态 RGB-D SLAM，时间一致性可以用于平滑动态概率、维持短时动态状态记忆，并抑制语义检测置信度波动。但过强的时间记忆也可能带来响应延迟，在快速运动目标或长时间遮挡情况下产生短时误判。因此，时间一致性建模需要与语义先验、运动一致性和对象级约束协同使用。本文方法正是在这一思路下，将时间概率递推引入动态目标判别过程，以提高动态场景下 SLAM 的长期稳定性。
