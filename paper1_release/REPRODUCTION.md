# Reproduction Notes

This repository snapshot freezes the code state for Paper1:

`基于时间一致性动态证据累积的语义 RGB-D SLAM 方法`

The code release is intended to reproduce the submitted Robot Journal experiments without modifying the Paper1 algorithm.

## Build

Build the ORB-SLAM2 RGB-D system and third-party libraries:

```bash
cd /home/djn/123/ORB_SLAM2_AddSemantic
chmod +x build.sh
./build.sh
```

The main RGB-D executable is expected at:

```text
Examples/RGB-D/rgbd_tum
```

## Main Configuration Files

- RGB-D camera parameters: `Examples/RGB-D/TUM3.yaml`
- Vocabulary file: `Vocabulary/ORBvoc.txt`
- TUM association files:
  - `dataset_associations/fr1_xyz_associate.txt`
  - `dataset_associations/fr1_desk_associate.txt`
  - `dataset_associations/fr3_walking_xyz_associate.txt`
  - `dataset_associations/fr3_walking_rpy_associate.txt`
  - `dataset_associations/fr3_walking_halfsphere_associate.txt`
  - `dataset_associations/fr3_walking_static_associate.txt`

## Main Run Commands

Run one TUM RGB-D experiment:

```bash
cd /home/djn/123/ORB_SLAM2_AddSemantic
python3 scripts/run_tum_rgbd_experiment.py \
  --sequence fr3_walking_xyz \
  --method full \
  --dataset /home/djn/123/datasets/TUMRGBD/rgbd_dataset_freiburg3_walking_xyz \
  --association dataset_associations/fr3_walking_xyz_associate.txt \
  --settings Examples/RGB-D/TUM3.yaml \
  --out-dir results/reproduction/fr3_walking_xyz/full_run_01 \
  --device cpu
```

Run lambda sensitivity analysis:

```bash
cd /home/djn/123/ORB_SLAM2_AddSemantic
python3 experiment_new/scripts/run_lambda_sensitivity_analysis.py
```

Run theta sensitivity analysis:

```bash
cd /home/djn/123/ORB_SLAM2_AddSemantic
python3 scripts/run_theta_sensitivity_analysis.py --device cpu --timeout-sec 900
```

Evaluate tracking success rate:

```bash
cd /home/djn/123/ORB_SLAM2_AddSemantic
python3 scripts/evaluate_tracking_success_rate.py
python3 scripts/prepare_tsr_paper_table.py
```

Run Bonn dynamic dataset experiment:

```bash

python3 experiment_new/scripts/evaluate_bonn.py
```

## Runtime Outputs

Runtime outputs such as `build/`, `results/`, per-run logs, trajectory text files, sockets, large datasets, model weights and bulk experiment folders are intentionally excluded from version control. They should be regenerated by the scripts above or restored from the experiment archive.
